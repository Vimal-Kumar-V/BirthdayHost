      Connect to GitHub

      Publishing saves the photos and wish into the repo. It needs a GitHub token that can edit that repo.

      1. Open GitHub → new fine-grained token.
      2. Under Repository access, pick Only select repositories and choose .
      3. Under Permissions → Contents, choose Read and write. Generate it and paste it below.

      The token stays in this browser only and is sent to nobody but GitHub. Without “remember”, it's forgotten when you close the tab.
